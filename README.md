# Tymofii Kuzmych Portfolio

Portfolio website created for a young artist as part of his university application. The site presents selected paintings, sketches, sculptures, and ceramics in a simple, visual format.

## Overview

This repository contains the source code for a portfolio website I designed and developed using Eleventy (11ty), CSS, Nunjucks, and vanilla JavaScript.

The project was built as a lightweight static site with a focus on visual content, performance, responsive behaviour, and straightforward navigation.

## Features

- **Artwork galleries:** Justified image grids for paintings, sketches, sculptures, and ceramics
- **Lightbox viewing:** Full-screen image viewing with PhotoSwipe
- **Section navigation:** Horizontal desktop nav and a themed mobile overlay menu
- **Responsive layout:** Designed for desktop, tablet, and mobile screens
- **Static-site architecture:** Lightweight Eleventy build with minimal client-side JavaScript

## Technologies

- **Static Site Generator:** Eleventy (11ty)
- **Templating:** Nunjucks
- **Styles:** Plain CSS with design tokens
- **JavaScript:** Vanilla JavaScript
- **Media:** ImageKit CDN, Flickr Justified Gallery, PhotoSwipe
- **Build Tools:** npm scripts, ESLint, Prettier
